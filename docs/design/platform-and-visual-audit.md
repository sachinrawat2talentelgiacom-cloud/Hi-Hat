# Platform and visual audit

## Platform fit

- Material 3 remains the native Android/Windows component foundation.
- Interactive controls use a minimum 48 logical-pixel height.
- Semantics identify interactive album surfaces and loading structures.
- Hover behavior augments desktop use without becoming required for touch.
- Platform animation preferences disable travel and timing.
- The system font stack remains intentional for native rendering, language coverage, and platform familiarity.

## Visual system

- Direction: quiet technical listening surface with tactical-telemetry metadata.
- Palette: near-black chamber, mineral text, muted trace, and one chartreuse signal.
- Hierarchy: content and titles first; metadata compact and tabular; actions explicit.
- Layout: responsive grids and ledgers use tokenized spacing and structure-matched loading states.
- Effects: no gratuitous gradients, scanlines, noise, glass, shimmer, or stacked shadows.
- Motion: short, composited, user-triggered, and reduced-motion aware.

## Conflicts resolved

Some skills target React/Tailwind websites or prescribe a fixed aesthetic. Hi Hat is a Flutter music application with an existing product brief. Stack-specific commands and effects that conflict with platform behavior, accessibility, performance, or the brief were not transplanted literally; their applicable design principles were executed in Flutter-native form.

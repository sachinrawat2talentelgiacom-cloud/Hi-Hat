# Audio fixture

`player_test.flac` is `gapless_3.flac` from the
[`exaile/exaile-test-files`](https://github.com/exaile/exaile-test-files)
test corpus. That repository states its files are contributed to the public
domain or derived from public-domain sources.

The fixture is a 10-second, mono, 16-bit/44.1 kHz FLAC used only to verify
validation, duration checks, personal-library acquisition, and player wiring.

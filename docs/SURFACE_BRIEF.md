# Application surface brief

- Mode: Operate. A listener searches, acquires, verifies, and plays a durable local FLAC with minimal interaction.
- Direction: Calibrated Silence. Anechoic charcoal fields, mineral type, acid-chartreuse live signal, machined circular transport, and artwork as the only vivid field.
- Compact composition: `.impeccable/mocks/search-mobile.png`; monumental search, result ledger, mini player, Material navigation.
- Expanded composition: `.impeccable/mocks/search-desktop.png`; rail, search/result ledger, and persistent player split by resize width.
- Core states: first-run, loading, empty, provider offline, downloading, verifying, transferring, local-ready, playing, and backend configuration.
- Constraints: 48dp targets, scalable type, keyboard focus, system Back, reduced motion, honest quality labels, no remote playback.
